# 내신 계산기

지금까지의 시험 성적을 입력하면, **목표 점수를 채우기 위해 마지막 시험에서 몇 점이 필요한지** 계산해 주는 웹사이트입니다. 과목별로 따로 저장되며, Google 로그인을 하면 다른 기기에서도 이어서 볼 수 있습니다.

## 주요 기능

- **과목 관리**: 사이드바의 `+` 버튼으로 과목을 추가하고, 과목 옆 `⋮` 메뉴에서 이름 바꾸기와 삭제를 할 수 있습니다.
- **시험 카드**: 정기고사 또는 수행평가를 골라 점수를 입력합니다. `+ 시험 추가`와 `−` 버튼으로 카드를 늘리고 지울 수 있습니다.
- **목표 점수**: 기본값은 90점이며 자유롭게 바꿀 수 있습니다.
- **마지막 시험 계산**: 남은 시험이 정기고사인지 수행평가인지 선택하면, 필요한 점수가 노란 카드에 바로 표시됩니다. 이미 달성했거나 만점을 받아도 어려운 경우에는 따로 안내합니다.
- **자동 저장**: 입력하는 대로 저장됩니다. 로그인하면 계정에, 로그인하지 않으면 이 브라우저에 저장됩니다.
- **반응형 화면**: 데스크탑에서는 왼쪽에 사이드바가 떠 있고, 모바일에서는 ☰ 버튼으로 사이드바를 열고 닫습니다. 라이트/다크 모드도 기기 설정에 맞춰 따라갑니다.

## 계산 방식

전체 반영 비율의 합을 100점으로 보고 계산합니다.

| 구분 | 입력 | 반영 점수 |
| --- | --- | --- |
| 정기고사 | 점수(100점 만점), 반영 비율(%) | 점수 × 반영 비율 ÷ 100 |
| 수행평가 | 점수, 만점 | 점수 (만점이 곧 반영 비율) |

마지막 시험에 필요한 점수는 다음과 같습니다.

- 남은 점수 = 목표 점수 − 지금까지 얻은 반영 점수의 합
- 마지막이 **정기고사**: 필요 점수 = 남은 점수 × 100 ÷ 마지막 시험의 반영 비율
- 마지막이 **수행평가**: 필요 점수 = 남은 점수 (만점은 직접 입력)

마지막 시험의 반영 비율(또는 만점)은 `100 − 지금까지 입력한 비율`로 자동 채워지고, 직접 고칠 수도 있습니다.

## 사용 방법

1. 사이드바의 `+`로 과목을 추가합니다.
2. `지금까지 본 시험`에 시험 카드를 추가하고 점수를 입력합니다.
3. `목표 점수`를 입력합니다.
4. `남은 마지막 시험`의 종류를 고르면 오른쪽(모바일에서는 아래) 노란 카드에 결과가 나옵니다.

## 기술 스택

- HTML, CSS, JavaScript (프레임워크 없이 `index.html` 한 파일)
- [Firebase Authentication](https://firebase.google.com/docs/auth): Google 로그인
- [Cloud Firestore](https://firebase.google.com/docs/firestore): 로그인한 사용자의 과목 데이터 저장
- GitHub Pages: 호스팅

## 데이터와 개인정보

- 로그인하면 과목 데이터가 Firestore의 `users/{내 계정 ID}` 문서에 저장됩니다. 다른 사용자는 읽을 수 없습니다.
- 로그인하지 않으면 데이터가 이 브라우저(`localStorage`)에만 저장됩니다. 브라우저 데이터를 지우면 함께 사라집니다.
- 사이트 운영자는 Firebase 콘솔에서 저장된 데이터를 볼 수 있지만 사용자의 구글 ID에 관한 정보는 볼 수 없습니다.
